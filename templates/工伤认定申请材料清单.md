# 工伤认定申请材料清单（模板）

> 适用：职工发生事故伤害或被诊断、鉴定为职业病后，向用人单位所在地统筹地区社会保险行政部门
> 申请工伤认定。单位应在 30 日内申请；单位不申请的，职工/近亲属/工会可在 1 年内申请
> （《工伤保险条例》第 17 条）。

## 三、申请时限与流程

```
事故发生/职业病确诊
   │
   ├─ 用人单位 30 日内 → 统筹地区社保行政部门申请工伤认定
   │
   └─ 单位不申请 → 职工/近亲属/工会 1 年内申请
                        │
                        ▼
              社保部门受理（材料补正 15 日内）
                        │
                        ▼
              作出工伤认定决定（一般 60 日内，事实清楚 15 日内）
                        │
                        ▼
              伤情稳定 → 劳动能力鉴定 → 工伤保险待遇
```

## 四、常见问题

1. **没有劳动合同**：先通过工资流水、考勤、工作群、工牌等证明事实劳动关系；必要时先申请劳动仲裁确认劳动关系。
2. **单位不配合**：职工可自行申请；向劳动保障监察投诉单位未参保/未申报。
3. **超期**：超过 1 年一般不再受理（有正当理由可争取）；尽早申请。
4. **未参保**：由用人单位按《工伤保险条例》规定的待遇项目和标准支付费用。
5. **对认定结论不服**：可申请行政复议或提起行政诉讼（注意期限）。

## 五、待遇项目速查（《工伤保险条例》第 30-45 条）

| 项目 | 内容 |
|---|---|
| 医疗费 | 符合目录的工伤医疗费用从基金支付 |
| 住院伙食补助、交通食宿 | 按统筹地区标准 |
| 停工留薪期工资 | 原工资福利待遇不变，单位按月支付（一般≤12 个月，可延长） |
| 生活护理费 | 经鉴定需要护理的，按生活自理障碍等级支付 |
| 一次性伤残补助金 | 一至十级，按本人工资的月数 |
| 伤残津贴 | 一至六级，按月支付（一至四级基金支付，五至六级单位支付） |
| 一次性工伤医疗补助金/伤残就业补助金 | 五至十级解除/终止时，按地方标准 |
| 工亡待遇 | 丧葬补助金、供养亲属抚恤金、一次性工亡补助金（上年度全国城镇居民人均可支配收入 20 倍） |
