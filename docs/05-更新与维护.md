# 更新与维护

## 1. 依赖

| 依赖 | 用途 | 安装 |
|---|---|---|
| Python 3.10+ | 全部脚本 | 系统自带 |
| pandoc | docx → markdown | `apt install pandoc` |
| LibreOffice（可选） | 老 .doc 兜底转换 | `apt install libreoffice` |
| Node.js（可选） | flk WAF 挑战求解 `scripts/waf_solver.js` | 系统自带 |
| PyYAML | front matter 解析 | `pip install pyyaml` |
| beautifulsoup4（可选） | 人社部/政府网页解析 | `pip install beautifulsoup4` |

## 2. 抓取

```bash
# 国家层面：法律/行政法规/司法解释/修改废止决定
python3 scripts/fetch_national.py --list      # 先看选中清单（不下载）
python3 scripts/fetch_national.py             # 抓取；--only laws 只跑一组；--refresh 忽略缓存

# 人社部部门规章 + 规范性文件
python3 scripts/fetch_mohrss.py

# 地方性法规（flk）
python3 scripts/fetch_local.py

# flk 未收录的 1978/1981 国务院文件
python3 scripts/fetch_gov_supplement.py
```

### flk WAF 处理

flk 前置 WZWS WAF，高频请求返回 HTML 挑战页。脚本已内置：

- 单线程 + `min_interval` 限速；
- 识别 HTML 挑战后长冷却重试；
- 可选 Node 求解：`node scripts/waf_solver.js <challenge.html> --raw` 得到 `/WZWSREL...` 通过 URL，
  GET 一次后携带 cookie 恢复。

若长时间被拦：降低频率、换出口 IP、或间隔一段时间再跑。**缓存**（`research/flk_cache/`）会让重跑很快。

## 3. 新增/修改一条法规

1. 在 `data/<层级>/` 下新建 Markdown，front matter 按 `SCHEMA.md` 填写；
2. 正文格式：`# 标题`、题注、`第X条` 段首、章/节用 `##/###`；
3. 运行：

```bash
python3 scripts/build_index.py   # 回填 sha256/chars/articles，重建索引
python3 scripts/verify.py        # 校验
```

如手工加了 `data/articles/*.json`，build 会覆盖；以 build 结果为准。

## 4. 状态与版本

- flk 的 `sxx` 映射：1 已废止、2 已修改、3 有效、4 尚未生效；
- 同一 `version_group` 的多个版本会在 `related` 中互链；
- 新版本发布后，重跑对应抓取脚本即可新增；旧版本保留（会标记“已修改”），不要删除。

## 5. 发布

```bash
git add -A
git commit -m "data: refresh labor-law corpus $(date +%F)"
git push
```

建议在发布前运行 `verify.py`，并检查 `data/stats.json` 的数量变化是否符合预期。

## 7. 常见问题

**Q：pandoc 报 “couldn't parse docx file”？**
A：文件实际是旧版 .doc（OLE 复合文档），用 `soffice --headless --convert-to docx` 转换后再 pandoc；
`docx2md.to_markdown` / `fetch_national.to_markdown` 已内置兜底。

**Q：条文数比官方少？**
A：先看 `data/articles/<id>.json` 是否按“第X条”切分；有些决定/意见用“一、二、”编号，没有条号属正常；
flk 的 `content` 目录树对行政法规/司法解释多为 null，不能作为唯一校验依据。

**Q：source 不是 https？**
A：`verify.py` 会报错；请改用官方 https 页面（人社部镜像路径可映射到 `https://www.mohrss.gov.cn/...`）。

**Q：地方性法规里出现“养老服务条例”等无关文件？**
A：说明筛选规则需调整；在 `scripts/fetch_local.py` 的关键词/排除规则中修改后重跑，并删除误收文件。
