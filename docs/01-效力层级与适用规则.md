# 效力层级与适用规则

劳动法不是一个单一法典，而是由**法律、行政法规、司法解释、部门规章、地方性法规**以及大量
规范性文件共同构成的规范群。回答具体问题时，除了找到“哪一条”，还要判断“这一条还有没有效、
和另一条冲突时用哪个”。

## 1. 效力层级

```
宪法
 └─ 法律（全国人大及其常委会）
     ├─ 法律解释、有关法律问题的决定
     ├─ 行政法规（国务院）
     │   ├─ 司法解释（最高法/最高检，对审判、检察工作适用法律作出解释）
     │   ├─ 部门规章（国务院组成部门，如人社部）
     │   └─ 地方性法规（省/市人大及其常委会）
     └─ （地方性法规不得与宪法、法律、行政法规相抵触）
```

- **法律**：劳动法、劳动合同法、就业促进法、劳动争议调解仲裁法、社会保险法、工会法、
  安全生产法、职业病防治法、妇女权益保障法、残疾人保障法、未成年人保护法、矿山安全法、
  特种设备安全法、危险化学品安全法、医疗保障法、职业教育法、人口与计划生育法、煤炭法、
  建筑法、退役军人保障法。
- **行政法规**：劳动合同法实施条例、劳动保障监察条例、工伤保险条例、失业保险条例、
  社会保险费征缴暂行条例、社会保险经办条例、职工带薪年休假条例、女职工劳动保护特别规定、
  禁止使用童工规定、使用有毒物品作业场所劳动保护条例、矿山安全法实施条例、安全生产许可证条例、
  建设工程安全生产管理条例、煤矿安全生产条例、危险化学品安全管理条例、特种设备安全监察条例、
  关于工资总额组成的规定、国务院关于职工工作时间的规定、住房公积金管理条例、残疾人就业条例、
  人力资源市场暂行条例、保障农民工工资支付条例、尘肺病防治条例、生产安全事故报告和调查处理条例、
  事业单位人事管理条例等。
- **司法解释**：如《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）（二）》，
  对仲裁与审判中的法律适用问题具有普遍约束力，实务中必须参考。
- **部门规章**：人社部制定的工资支付暂行规定、最低工资规定、劳务派遣暂行规定、工伤认定办法、
  企业职工带薪年休假实施办法、劳动人事争议仲裁办案规则等。
- **地方性法规**：各省/市人大制定的工资支付、劳动监察、工会、安全生产、女职工保护等条例，
  在本行政区域内有效，不得与上位法冲突。

## 2. 冲突适用规则

1. **上位法优于下位法**：法律 > 行政法规 > 部门规章/地方性法规。
   地方性法规与部门规章冲突时，由国务院提出意见/全国人大常委会裁决（立法法）。
2. **新法优于旧法**：同一机关制定的规范，新的规定与旧的规定不一致的，适用新的规定。
   - 例：劳动法（1994）与劳动合同法（2007）在劳动合同解除、经济补偿等问题上不一致的，
     优先适用劳动合同法；劳动合同法没有规定的，仍可适用劳动法。
3. **特别法优于一般法**：同一机关制定的特别规定与一般规定不一致的，适用特别规定。
   - 例：女职工劳动保护特别规定 相对于 劳动法 的通用劳动保护条款；
     工伤保险条例 相对于 社会保险法 的一般规定（在工伤领域优先适用条例）。
4. **法不溯及既往**：原则上新法不溯及既往，但“有利溯及”等例外按立法法/司法解释处理。
   处理旧案时必须用**行为发生时**有效的版本（用 `version_group` 找历史版本）。
5. **司法解释的时间效力**：司法解释施行后，法院尚未审结的一审、二审案件适用新解释；
   但解释另有规定的除外（如劳动争议解释（一）对旧解释的衔接安排）。

## 3. 劳动法 vs 劳动合同法（最常见的“新旧/一般特别”问题）

| 问题 | 劳动法（1994，2018 修正） | 劳动合同法（2007，2012 修正） | 适用 |
|---|---|---|---|
| 书面劳动合同 | 第16条要求订立 | 第10条：用工之日起一个月内订立；第82条：超期二倍工资 | 劳动合同法 |
| 无固定期限合同 | 第20条（连续工作满10年等） | 第14条（连续满10年、连续两次固定期限等） | 劳动合同法（更具体） |
| 试用期 | 第21条（最长6个月） | 第19条（按合同期限分档） | 劳动合同法 |
| 经济补偿 | 第28条（解除）、第91条（赔偿） | 第46、47条（补偿标准） | 劳动合同法；劳动法未覆盖部分仍适用 |
| 违法解除 | 第98条（赔偿） | 第87条（二倍经济补偿作为赔偿金） | 劳动合同法 |
| 加班费 | 第44条（150%/200%/300%） | 未规定 | 劳动法 + 工资支付暂行规定第13条 |
| 最低工资 | 第48条 | 未规定 | 劳动法 + 最低工资规定 |

> 记忆口诀：**劳动合同的订立、履行、变更、解除、终止**看劳动合同法及实施条例；
> **工时、工资、劳动安全、女职工/未成年工、社会保险**看劳动法及其配套法规；
> **争议程序**看劳动争议调解仲裁法；**工伤**看工伤保险条例 + 社会保险法。

## 4. 时效性判断清单

引用任何一条前，按顺序确认：

1. 该文件 `status` 是否为「有效」；
2. `effective`（施行日期）是否已到（`status=尚未生效` 的不能作为当前依据）；
3. 是否被同一 `version_group` 的更新版本取代（`related` 中会列出）；
4. 是否被其他法律/行政法规整体废止（如《劳动保险条例》《煤矿安全监察条例》《企业劳动争议处理条例》）；
5. 是否为地方性法规（只能在对应省市适用）；
6. 是否是部门规章/规范性文件（不能与法律、行政法规冲突，且法院仅“参照”规章）。

本语料库的 `status` 直接来自国家法律法规数据库的“时效性”字段，`notes` 中可能补充废止依据。

## 5. 地方规定的适用

- 地方性法规在本行政区域内有效；地方**规章**（省市政府规章）不在本语料库的“地方性法规”层级内，
  引用时注意区分。
- 同一问题各地标准不同（最低工资、高温津贴、产假天数、一次性工伤医疗补助金等），
  必须按用工地/用人单位所在地确定，不能直接套用外省规定。
- 地方规定与上位法冲突的，适用上位法；但地方在不低于国家标准的前提下可以作出更有利于劳动者的规定。

## 6. 规范性文件（红头文件）的定位

人社部及地方人社部门的“通知”“意见”“办法”（非规章）数量庞大，本语料库只收录其中少量
与部门规章重合的部分。实务中它们对执法、经办有直接影响，但不属于法的渊源，法院审理时
仅作参考。引用时应注明文号，并优先找到其上位法依据。

## 7. 国际劳工公约

中国批准的国际劳工公约（如第100号同工同酬、第111号就业歧视、第138号最低就业年龄、
第182号最恶劣形式童工）对我国有约束力，但需通过国内法实施；本语料库未收录公约文本，
涉及涉外/出口合规时另行检索。
