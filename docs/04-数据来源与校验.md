# 数据来源与校验

## 1. 权威来源

| 来源 | 用途 | 地址 |
|---|---|---|
| 国家法律法规数据库 | 法律、行政法规、司法解释、地方性法规、修改/废止决定的**正文与效力状态** | https://flk.npc.gov.cn |
| 人力资源和社会保障部 | 部门规章（部令）、部分规范性文件 | https://www.mohrss.gov.cn |
| 中国政府网 / 地方政府门户 | flk 未收录的少数国务院文件（如 1978 年退休退职办法、1981 年探亲规定） | https://www.gov.cn 、地方政府门户 |

所有正文均来自官方发布的 **.docx 原件**（flk）或官方网页正文（人社部、政府门户），不使用商业法律数据库
或二手转载。每条数据在 front matter 的 `source` 字段可回溯到具体官方页面。

## 2. flk 接口（抓取实现见 `scripts/flk_client.py`）

国家法律法规数据库是 Vue SPA，数据接口为同源 JSON 接口：

```
POST https://flk.npc.gov.cn/law-search/search/list
     {"searchRange":1,"searchType":1,"searchContent":"劳动",
      "sxx":[],"flfgCodeId":[210],"zdjgCodeId":[],"sxrq":[],"gbrq":[],
      "pageNum":1,"pageSize":100}
GET  https://flk.npc.gov.cn/law-search/search/flfgDetails?bbbs=<bbbs>
GET  https://flk.npc.gov.cn/law-search/download/mobile?format=docx&bbbs=<bbbs>&fileId=
     302 -> https://flkoss.obs-bj2.cucloud.cn/...（OBS 签名地址，1 小时有效）
```

- `flfgCodeId`：法律叶子分类 110/120/130/140/150/155/160/170，行政法规 210，
  司法解释 320/330/340，地方性法规 230，修改废止决定 200/215/350。
- `sxx`：1 已废止、2 已修改、3 有效、4 尚未生效；详情里 `content` 是目录树（部分文件为 null）。
- `bbbs` 是 flk 的全局唯一 ID，本仓库的 `id` 为 `flk-<bbbs>`。

### WAF 说明

flk 前置 WZWS WAF，高频请求会返回 HTML 挑战页。处理方法：

1. 低速率（`FlkClient(min_interval=1.2)`，单线程）；
2. 识别到 HTML 后长冷却重试（`_request` 内置 90s+ 退避）；
3. 可选：用无头 Chrome 过挑战（`scripts/waf_browser.py`）或 Node 求解 `WZWSREL` 跳转（见 `scripts/`）。

> 抓取脚本可重跑、幂等：已存在的 docx 跳过下载，详情 JSON 缓存在 `research/flk_cache/`。

## 3. 人社部

- 官网对非浏览器 UA 返回 JS WAF 页面；抓取时使用镜像 IP `114.255.111.133`（同路径、内容一致），
  入库时 `source` 统一写回 `https://www.mohrss.gov.cn/...` 规范地址。
- 规章列表：`/xxgk2020/fdzdgknr/zcfg/bmgz/`、`/xxgk2020/gzk/gz/`；详情页含发文字号、发文日期、是否有效。
- 正文从 HTML 清洗：去导航/页脚、合并被逐字拆行的数字与标点、保留“第一条…”结构。

## 4. 转换与归一化（`scripts/docx2md.py`）

1. `pandoc <docx> -t gfm --wrap=none`；少数实际为 .doc 的文件用 LibreOffice 转 docx 兜底；
2. 去 BOM、统一换行、去行首缩进（全角/半角空格）；
3. 章/节标题转为 `##`/`###`（有“编”时降级），条号保持段首；
4. 合并多余空行，保留官方题注（通过/修正/施行说明）与目录；
5. 解析“第X条”为 `data/articles/<id>.json`，中文数字转阿拉伯数字。

## 5. 校验（`scripts/verify.py`）

| 检查 | 说明 |
|---|---|
| front matter 必填字段 | id/title/level/issuer/promulgated/effective/status/topics/source/… |
| sha256 | 与正文重新计算值比对，防止手工改正文未重建索引 |
| 条文数 | `articles` 与 `data/articles/<id>.json` 一致 |
| 占位/错误文本 | 不得含“系统异常”“Please enable JavaScript”等 |
| 核心法规齐备 | 劳动法、劳动合同法、社会保险法、工伤保险条例等 15 部必须存在且有效 |
| 来源合法性 | https、官方域名 |
| 重复 | 同一 title+promulgated 不得重复 |

同时 `data/manifest.json` 记录了每篇的抓取来源、条文数（解析值 vs 官方目录树）、sha256。

## 6. 覆盖范围与已知缺口

**已覆盖**
- 法律：劳动法、劳动合同法、就业促进法、劳动争议调解仲裁法、社会保险法、工会法、安全生产法、
  职业病防治法、妇女权益保障法、残疾人保障法、未成年人保护法、矿山安全法、特种设备安全法、
  危险化学品安全法、医疗保障法、职业教育法、人口与计划生育法、煤炭法、建筑法、退役军人保障法
  （含历史版本与相关批准决议）。
- 行政法规：劳动合同法实施条例、劳动保障监察条例、工伤保险条例、失业保险条例、社保费征缴/经办条例、
  年休假条例、女职工特别规定、禁止使用童工规定、有毒物品劳动保护条例、矿山安全法实施条例、
  安全生产许可证条例、建设工程安全生产管理条例、煤矿安全生产条例、危化品条例、特种设备安全监察条例、
  工资总额组成规定、职工工作时间规定、住房公积金条例、残疾人就业条例、人力资源市场暂行条例、
  保障农民工工资支付条例、尘肺病防治条例、生产安全事故条例、事业单位人事管理条例、退休退职/探亲规定等。
- 司法解释：劳动争议解释（一）（二）及历史解释、工会法解释、工伤保险行政案件规定、
  拒不支付劳动报酬刑事案件解释、人事争议规定/批复等。
- 部门规章：人社部现行及历史部令 71 件（工资支付、最低工资、集体合同、劳务派遣、工伤认定、
  年休假实施办法、仲裁办案规则、社保经办、超龄劳动者规定等）。
- 地方性法规：按劳动主题关键词从 flk 抓取，589 篇，覆盖 31 个省级行政区（见 `data/local-regulations/`）。
- 规范性文件：劳动关系认定、工资折算、新就业形态、非全日制、实习管理等 10 篇。

**不在范围内**
- 地方**政府规章**、地方规范性文件（红头文件）；
- 人社部及其他部门的“通知/意见/复函”等规范性文件（仅少量与规章同源者）；
- 指导性案例、典型案例、会议纪要；
- 国际劳工公约；
- 已从官方数据库下架的极早期文件（部分用政府门户补齐）。

**已知数据特点**
- flk 对行政法规、司法解释的 `content` 目录树多为 null，条文数只能由 docx 正文自校验；
- 旧 .doc 文件（如部分地方条例）转换后可能存在空格/标点差异，已尽量归一化；
- 少数地方性法规原文使用 Word 自动编号，转换后部分条号未落到正文（如《广州市实施〈工会法〉办法》
  缺 12、22-24、28 条号），导致条文拆分数量略少于实际；正文文字未缺失，已在 `data/articles` 中保留
  可解析的条文，检索时可按内容命中；已知共 6 篇，后续会尝试用编号还原修复；
- 地方性法规为“标题关键词命中 + 人工规则去噪”的集合，不保证覆盖每一个地级市；
- 状态以抓取时 flk/人社部标注为准，可能滞后于最新修改。

## 7. 复现

```bash
python3 scripts/fetch_national.py --list   # 先看选中的国家层面清单
python3 scripts/fetch_national.py          # 抓取国家层面（法律/行政法规/司法解释/决定）
python3 scripts/fetch_mohrss.py            # 抓取人社部规章（如存在）
python3 scripts/fetch_local.py             # 抓取地方性法规（如存在）
python3 scripts/fetch_gov_supplement.py    # 补齐 flk 未收录的 1978/1981 国务院文件
python3 scripts/build_index.py
python3 scripts/verify.py
```
