# 使用指南

本仓库既是一个**法规语料库**，也是一个可被 agent 直接调用的**技能**。所有检索都在本地完成，
不需要联网；法规文本来自官方渠道的 docx 原件，经统一转换与校验。

## 1. 先看全局

```bash
python3 scripts/search.py --stats
```

输出示例（字段含义见下）：

```json
{

      "notes": "",

```

- `status`：`有效` / `尚未生效` / `已修改` / `已废止`；`status_code` 对应 3/4/2/1。
- `level` 决定效力层级；`version_group` 相同的文件是同一法规的不同版本，`related` 已互链。
- `age_groups`：年龄维度标签（如“超龄/退休返聘”“16-18岁（未成年工）”），可用 `--age` 过滤。
- `articles/*.json`：`{"id": "...", "title": "...", "articles": [{"no": "第三十九条", "n": 39, "chapter": "…", "section": "", "text": "…"}]}`。

## 3. 检索模式

### 3.1 主题检索

```bash
python3 scripts/search.py 加班费
python3 scripts/search.py 竞业限制 经济补偿          # 默认 AND
python3 scripts/search.py 竞业限制 经济补偿 --any    # OR
```

排序依据：标题命中 > 主题标签命中 > 条文命中次数 > 现行有效优先。每条结果给出法规、
层级、时效、路径、官方来源，以及命中的条文片段（`--snippets` 控制条数）。

### 3.2 过滤

| 参数 | 取值 |
|---|---|
| `--level` | 法律 / 行政法规 / 司法解释 / 部门规章 / 地方性法规 / 规范性文件 / 修改废止决定 |
| `--status` | 有效 / 尚未生效 / 已修改 / 已废止 |
| `--topic` | 劳动基准 / 劳动合同 / 集体合同与工会 / 就业促进 / 职业培训 / 劳动安全卫生 / 特殊群体保护 / 社会保险 / 工资保障 / 劳动争议处理 / 劳动保障监察 / 新就业形态 / 人事关系 / 涉外用工 / 综合/其他 |
| `--province` | 如 北京市、广东省（地方性法规） |
| `--age` | 未满16 / 16-18 / 育龄女性 / 临近退休 / 超龄 / 在校生 / 残疾人 / 退役军人 / 青年 / 高龄 |
| `--year` | 公布或施行年份，如 2021 |
| `--limit` | 返回条数，默认 10 |

### 3.3 单篇与条文

```bash
python3 scripts/search.py --doc 劳动合同法
python3 scripts/search.py --doc 劳动合同法 --article 39
python3 scripts/search.py --doc flk-ff8080816f135f46016f20f16ee11737 --article 第四十四条
```

`--doc` 先按 id 精确匹配，再按标题子串匹配；`--article` 支持阿拉伯数字与中文条号。
无 `--article` 时输出元数据 + 章目录 + 条号列表。

### 3.4 列目录 / JSON / 统计

```bash
python3 scripts/search.py --list --level 司法解释
python3 scripts/search.py --list --province 上海市 --limit 100
python3 scripts/search.py 工伤 --json > /tmp/hits.json
python3 scripts/search.py --topics
```

## 4. 直接读 Markdown

每条法规就是一篇带 YAML front matter 的 Markdown：

```
data/laws/中华人民共和国劳动法-2018.md
data/administrative-regulations/工伤保险条例-2010.md
data/local-regulations/北京市/北京市工资支付规定-2003.md
```

正文中 `## 第X章`、`### 第X节` 为标题，`第X条` 起新段。适合 agent 用 `Read` 精读上下文，
或 `grep` 做更复杂的模式匹配（例如查找“视为”“不得”“应当”条款）。

## 5. 改数据后

```bash
python3 scripts/build_index.py   # 重建 index.json / articles / INDEX.md
python3 scripts/verify.py        # 校验哈希、条文数、核心法规是否齐全
```

`build_index.py` 会把 `sha256/chars/articles` 回填到 front matter。`verify.py` 失败时先看报错，
常见原因是手工改了正文但没重建索引，或 front matter 字段缺失（见 `SCHEMA.md`）。

## 6. 典型 agent 用法

```text
1. search.py 未签劳动合同 二倍工资 --status 有效
2. 命中《劳动合同法》第八十二条 → search.py --doc 劳动合同法 --article 82
3. Read data/laws/中华人民共和国劳动合同法-2012.md（看第十条、第十四条、第八十二条上下文）
4. 回答：引用条文原文 + 说明“用工之日起满一个月的次日至满一年的前一日”计算规则
5. 如涉及地方口径，再 search.py --province <省> 未签合同
```
